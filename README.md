# Guitarplayer For NTE · 异环吉他编曲器

Windows 桌面吉他编谱与自动演奏工具，by Akari。当前版本 **v0.12.11**，提供独立 EXE，无需安装 Python。

## 下载与教程

[下载 v0.12.11 Windows 便携包](https://github.com/DIEtype/Guitarplayer-For-NTE/releases/download/v0.12.11/NTE-Guitar-Player-v0.12.11-Windows.zip) · [全部版本](https://github.com/DIEtype/Guitarplayer-For-NTE/releases)

[视频教程 · Bilibili](https://www.bilibili.com/video/BV1UMnL6yEkV/) · [百度网盘备用入口](https://pan.baidu.com/s/1Zk7ZYHZxvSpX1IQWtjLZGw?pwd=9w2e)，提取码 **9w2e**。网盘内文件版本以实际提供的文件为准。

完整解压到可写的文件夹，双击 **NTEGuitarPlayer.exe**。游戏演奏会申请管理员权限，以匹配游戏权限；离线编谱可带 `--no-admin` 启动。程序使用明音凛头像图标，来源说明见 [assets/icon-source.md](assets/icon-source.md)。

升级前关闭旧窗口，保留原目录的 `library/` 和 `settings/`，再替换程序。曲库、校准、个人节奏预设与引导状态保存在本机，不随发布包提供。

## 这次更新

- **首次使用引导**：第一次启动，卡片逐步介绍曲谱来源、手动编谱、本地试听、游戏窗口、校准和自动演奏，并高亮对应按钮。完成、跳过或关闭后，后续启动不再自动弹出；右上角“使用引导”可重新查看。日常操作没有悬浮提示。
- **主界面重新分组**：蓝色“导入 MIDI／我的曲库”、青色“手动编谱”和粉色“5 秒后自动演奏”区分常用操作。较少使用的选项集中到“曲谱工具”和“游戏设置”，小窗口会自动换行。
- **圆盘显示同步**：按实际演奏谱的起音显示和弦／品格、页码、拨弦和扫弦方向；提前准备的选区另行提示。修正混合模式页码与扫弦高亮。亮弦代表本次起音，不表示游戏的实际延音或发声结果。
- **移调与异常音核对**：改进移调比较的运算效率；失败后可定位异常音、核对声部、手动指定去留，再重新生成。受保护的主旋律只作整曲统一移调，不局部降八度。
- **教程与更新入口**：内置离线使用说明、视频教程和网盘入口；启动时可检查 GitHub 正式版并提示更新，保留手动检查开关。不会自动替换程序。

## 从哪里开始

- 已有 MIDI：点 **导入 MIDI**，选择主旋律所在轨道和导入方式。默认“混合转译：主旋律优先”，启用自动升降调与低音伴奏过滤。
- 已有曲谱：点 **打开曲谱**，或到 **我的曲库** 选择收藏文件。
- 自己写谱：点 **手动编谱**，在六线谱上点弦、键入品位，用音符图形设置时值。
- 想试用功能：在 **曲谱工具 → 载入试弹《小星星》** 打开示例。
- 想查完整用法：在 **曲谱工具 → 完整使用说明** 打开离线说明；右上角 **使用引导** 重看分步介绍。

先用“本地试听”核对乐曲，再准备游戏连接。原谱在编谱窗口试听；本地合成参考音不能证明游戏已收到输入。

## 第一次在游戏演奏

1. 游戏进入吉他界面，在主窗口 **游戏窗口** 中选中它；没有找到时点“刷新”。
2. 在右侧 **游戏当前** 填写实际模式、音色和页码。这些是起始状态，需要按游戏实际画面核对。
3. 点 **校准布局**，可自动切回游戏截取客户区、导入截图或手动拾取。核对圆盘与扫弦点，再应用校准；窗口大小或 UI 比例变化后重新校准。
4. 点 **输入测试**，先测试单弦拨弦，再测试选区、翻页与扫弦。
5. 点击 **5 秒后自动演奏**，倒计时内切回游戏吉他界面。F8 暂停／继续，F9 停止；快捷键是否可用以主界面提示为准。失去游戏焦点会停止并释放输入。

混合演奏前，到 **游戏设置 → 分模式起始页** 分别填写和弦与品格模式保留的页码；两者都停在第一页时保持 1／1。

圆盘是程序的演奏谱预览，没有回读游戏画面或声音。提前选区可以先于下一次起音发生，圆盘会另行标明准备动作。

## 手动编谱

六线谱从上到下为吉他 1～6 弦，数字表示品位，`0` 是空弦。点击弦线并输入数字，用音符图形选择全音符至六十四分音符，支持附点、三连音、休止和跨小节延音。顶部可设置 BPM、拍号、音色与 Capo；小节设置可以标记后续生效的速度、拍号和音色变化。

同一份原谱可写和弦标记、逐弦 `X／●`、数字品位，以及上下扫弦；支持分解和弦与扫弦节奏预设。先写好小节，再用“节奏预设…”保存为个人预设，可跨曲目复用。

- **直接载入原谱**：保留所写音符、和弦、弦号与节奏。暂时不能原样演奏的内容仍可载入、编辑、试听和保存。
- **近似转译…**：另行生成游戏能表达的近似演奏谱，核对主旋律、伴奏、实际按法与省略音。
- **Del／Backspace**：删除选中弦的音符，保留其他弦、时值及后续位置。
- **Insert**：插入空节拍；**Ctrl+Del** 删除整列节拍；**Shift+Del** 清空整列音符并保留时值。节拍移动限制在当前小节，下一小节保持原位。
- **T／Shift+T**：连接／断开相邻同音的延音；长音可延续到下一小节的空位。
- **小节与反复**：支持前后插入小节、Shift 连选、复制、覆盖或插入粘贴、`%` 重复前小节和段落反复线。

Capo 保持谱面相对品位不变，提高实际音高；混合谱与游戏预设和弦不直接套用 Capo。

## MIDI 与近似转译

可读取 `.mid／.midi`、本程序 `.gscore` 和 TAB 文本。MIDI 可选择非鼓轨，保留速度变化及位于小节边界的拍号变化，也可选择单音旋律或纯品格指弹近似。

自动升降调比较原调及升降各 1～24 半音。标准定弦 0～24 品使用 E2～E6；若必须保留的旋律跨度或时序无法适配，程序保留失败位置与原因，不将局部高音降八度来凑音域。

“过滤 E2 以下伴奏”按移调后的音高判断，只处理识别为伴奏的低音；主旋律、指定保留、待核对音和明确扫弦不删。“声部与去留”可核对推断结果并手动标记。失败后可在“移调比较”选中方案，点“定位失败音 → 声部核对”。

原始 MIDI 保留。混音音频自动转出的 MIDI 可能混有其他乐器、泛音或错误音，应先试听原 MIDI、确认旋律轨。路线搜索和和弦匹配是近似处理，不保证复杂原谱的所有音都能原样演奏。

Bm 2 弦的理论音高仍为 D4；自动转译默认临时避开异常弦及会触及它的 Bm 全扫弦，手写指令保留。游戏修复后可在转译窗口关闭规避。

## 输入方式与节奏设置

在 **游戏设置 → 鼠标与手柄** 选择圆盘、拨弦、翻页与扫弦的输入方式：

- 游戏数字键 `1～6` 对应吉他 `6～1` 弦。
- 上扫为 `1→6` 弦，鼠标左键或右摇杆上推；下扫为 `6→1` 弦，鼠标右键或右摇杆下推。手柄两次扫弦之间自动回中。
- 虚拟手柄单弦 `1～6` 对应十字键下、左、右、上、A、X；上一页／下一页为 LB／RB。
- 左摇杆选择圆盘为试验功能，选择保持可单独调整。模式切换 Z、音色切换 V 仍使用键盘。

虚拟手柄需要另行安装 ViGEmBus；程序不会自动安装驱动。键盘、鼠标输入不依赖它。安装来源与许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。

在 **游戏设置 → 输入时序与日志** 调整档位、最短按键、按谱面时值保持和自适应衔接。通常先保留“稳拍自适应”。日志调优只统计本机输入调用与调度耗时，不能确认游戏是否发声；样本不足时使用默认值，不改 BPM 或音符起拍。

## 源码运行

仓库包含当前源码与必要运行依赖，建议使用 Python 3.13 和 Tk，双击 `start.cmd`，或运行 `python main.py --no-admin`。普通用户直接使用 Releases 中的独立 EXE。

项目与《异环》官方无关联。角色与游戏素材归其权利方；随包依赖许可见 [THIRD_PARTY.md](THIRD_PARTY.md)。
