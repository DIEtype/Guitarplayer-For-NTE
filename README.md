# Guitarplayer For NTE · 异环吉他编曲器

Windows 桌面吉他编谱与自动演奏工具。当前发布版本 **v0.12.3**，提供独立 EXE，无需安装 Python。

## 下载

[下载 v0.12.3 Windows 便携包](https://github.com/DIEtype/Guitarplayer-For-NTE/releases/download/v0.12.3/NTE-Guitar-Player-v0.12.3-Windows.zip) · [全部版本](https://github.com/DIEtype/Guitarplayer-For-NTE/releases)

完整解压到可写的文件夹，双击 **NTEGuitarPlayer.exe**。正常演奏会申请管理员权限，以匹配游戏权限；离线编谱可带 `--no-admin` 启动。程序与窗口使用明音凛头像图标，图标来源和制作说明随包提供。

升级时保留原目录的 `library/`、`settings/` 和需要留存的 `logs/`；关闭旧窗口后再替换 EXE。发布包不包含个人曲库、校准配置或演奏日志。

## v0.12.3 更新

- **MIDI 自动升降调**：新增 ±24 半音比较，共 49 个整体移调方案；保留原来的仅降调选项。MIDI 默认“混合转译：主旋律优先”，启用自动升降调和 E2 以下伴奏过滤，原文件不改写。
- **低音伴奏过滤**：按移调后的音高处理 E2 以下伴奏；主旋律、指定保留、待核对音和明确扫弦不删。被过滤的独立起拍保留为休止，后续音符保持原位；“声部与去留”和逐音报告列出处理结果。
- **更明确的失败指引**：文件损坏、计时格式不支持、空轨和音域不适配分别提示处理步骤。全部移调方案失败时可查看具体位置、核对旋律通道或换轨；长错误详情可滚动阅读。
- **直接载入与近似转译分开**：图形编谱右下角的青色“直接载入原谱”保留所写弦号、品位、和弦与节奏；橙色“近似转译…”单独选择。暂时无法原样演奏的原谱仍可载入、编辑、试听和保存。
- **编谱工具重排**：“音符与奏法”和“小节与反复”分开；范围选择、复制粘贴、插入设置、重复记号按组排列。连续录入失败的原因直接显示在弹窗中。
- **节奏预设**：13 组分解、扫弦与混合节奏，支持保存当前小节为个人预设、更新、改名和删除；低音弦可随和弦自动适配。预设保存在本机，可跨曲目使用。
- **小节复制与反复**：Shift 连选小节，Ctrl+C 复制、Ctrl+V 覆盖、Ctrl+Shift+V 插入；支持指定范围、目标和次数。支持 % 重复前小节与段落反复线，试听、转译按记号展开；可撤销和重做。
- **所有速度档共用自适应衔接**：独立开关协调选区准备、重复音和扫拨交接，保留各档最短按下与等待设置，音符起拍和 BPM 保持原样。
- **Bm 临时规避**：音高表仍将 Bm 2 弦记作理论 D4；自动转译默认避开该弦及会触及它的 Bm 全扫弦。手写 Bm 指令保留，游戏修复后可在转译窗口关闭规避。

### MIDI 音域不匹配时

在“导入 MIDI”选择主旋律所在轨，使用“混合转译：主旋律优先”。自动升降调会比较原调和升降各 1～24 半音；低于 E2 的主音可尝试整体升调，高于 E6 的主音可尝试降调。过滤只处理识别为伴奏的低音，判断不确定的音保留。

若必须保留的音域无法放入 E2～E6，或需要移调超过 ±24 半音，会提示核对轨道／主旋律通道。每个调内部使用有限宽度的近似路线搜索，不保证所有声部都能原样演奏；时序空间不足仍需调整谱面或速度。

### 使用个人节奏预设

写好一个小节，点“节奏预设… → 保存当前小节…”，命名后出现在“我的预设”。保存时值、休止、弦位及扫弦方向；数字品位会转为目标和弦的弦位击奏，不作为原旋律保存。应用时核对拍号、和弦及低音弦；已有预设可右键“用当前小节更新此预设…”。关闭预设窗口前，可撤销最近一次删除。

## v0.11.7 更新

- **稳拍快速**：保留快速档的 30 毫秒最短按下与选择保持，提前安排选区准备；重复拨弦／扫弦额外预留 15 毫秒松开余量。音符起点与 BPM 保持原样，重复音的实际保持可能略短，最短按下时长仍保留。需开启“拨弦与扫弦按谱面时值保持”。
- **报错直接定位**：显示事件所在小节、拍位、和弦／品格、拨弦动作、实际迟到和本次阈值，方便返回谱面查找。
- **右摇杆扫弦**：上推为上扫（1→6 弦），下推为下扫（6→1 弦），两次扫弦之间自动回中；可用鼠标选择下一和弦，同时保留旧扫弦的输入保持。
- **手柄拨弦与翻页**：1～6 弦依次对应十字键下、左、右、上、A、X；上一页／下一页为 LB／RB。按钮与双摇杆共用完整状态，释放单项不会清空其他仍保持的输入。
- **左摇杆选择圆盘（试验）**：适用于和弦、品格及混合演奏；默认保持 60 毫秒，可独立设置 40～200 毫秒。“快速／极速”不会将其缩成 15／10 毫秒脉冲。六扇区测试包含 300 毫秒慢速及当前演奏保持时长两轮。

### 选择输入方式

在主窗口点“扫弦方式”，分别设置扫弦、拨弦、翻页与圆盘选择。默认仍可使用键盘和鼠标；模式 Z、音色 V 沿用键盘。鼠标选区需校准圆盘坐标；左摇杆选择配合右摇杆扫弦时可省去鼠标坐标校准。

可选虚拟手柄功能需要另行安装 [ViGEmBus v1.22.0 官方驱动](https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0)，程序不会自动安装，也不附带驱动安装器。该项目已停止维护；键盘与鼠标输入不依赖它。安装后可在“扫弦方式”中检查驱动并运行各项输入测试，无需连接实体手柄。

实际尾音长度由游戏采样决定；延长输入保持不保证声音持续同样久。快速选区与同拍组合的接受情况仍需在游戏中确认。主机持续卡顿或准备空间不足时仍会停止，稳拍快速不改变整曲时间轴来补偿延迟。

## v0.11.2 更新

- **主旋律与声部分类**：MIDI 保留通道、力度和原始结束时间作为线索，支持指定旋律通道、逐音修正角色；“声部与去留”展示分类依据及实际输出。
- **失真段伴奏简化**：默认“旋律＋稀疏低音”，保留低音节拍骨架，优先简化内声部；也可保留全部或仅主旋律。清音段、明确扫弦和待核对音默认保留。
- **装饰音适配**：先尝试原样起音，再提前安排；必要时合并或省略并记录。移调评分纳入这部分丢音，主动伴奏简化单独报告。
- **长曲操作优化**：后台转译提供进度与取消；只绘制可见小节，播放时间线只移动游标，并缓存变速时间索引。
- **独立输入调度**：不同数字键可在上一弦保持时触发，并提前准备下一次选择；同键重触发、翻页及 Z／V 切换仍保留必要间隔。

在“指弹转译”中选择伴奏策略，并在“声部与去留”核对分类、修正和试听后应用。旧曲库、设置及原谱保留。自动分类属于规则推断，复杂声部可手动指定；快速输入的接受情况仍以游戏表现为准。

- **按住时值**：和弦、品格及混合模式的数字键拨弦，以及鼠标左右扫弦，按谱面时值保持；支持 BPM 变化和跨小节延音。
- **起音保持准拍**：数字键的松开独立于翻页、选择和模式切换；同一按键再次起音前留出短暂松开间隔。
- **扫弦切换提示**：鼠标选择前提前松开正在保持的扫弦，避免拖动；主界面提示缩短位置和时间。
- **默认开启，可切回短按**：“拨弦与扫弦按谱面时值保持”随曲谱保存；“最短按键毫秒”保障输入识别。
- **新增示例**：`examples/按住时值_拨弦与扫弦对比.gscore`，从和弦模式第一页开始，对比长短音、双弦、扫弦、切模式与跨小节延音。

## v0.11.0 更新

- **逐弦修改**：Del／Backspace 默认只删选中弦的音，保留同拍其他音、时值与后面的位置。`8` 改成 `7` 可直接键入 `7`，连续输入 `12` 仍表示十二品。
- **插入节拍**：Insert 打开独立的音乐时值选择窗口，支持附点和三连音；选择插入时值不会改动当前音。本小节空间不足时提示调整，下一小节保持原位。
- **明确的整列操作**：Shift+Del 清空整列音符并保留时值；Ctrl+Del 删除整列节拍并将本小节后续音符前移。支持 Ctrl+Z 撤销和 Ctrl+Y 重做。
- **统一编曲**：主界面与指弹转译采用同一个六线谱编辑器，可混写数字品位、和弦标记、逐弦 X／点和上下扫弦。
- **自动降调**：整曲比较原调至降低 24 个半音的方案，兼顾节奏可行性、丢音、切模式与翻页；保留旋律音程和原始起拍。可比较方案，并试听原谱与转译结果。
- **跨小节延音**：长音可延续到下一小节空位，谱面显示延音线，小节线处不重复拨弦。T 连接相邻同音，Shift+T 断开跨小节延音。
- **混合演奏**：在预设和弦与品格之间自动用 Z 切换；MIDI 指弹近似优先保留旋律起拍，尽量保留低音与内声部。

## 使用

1. 在游戏中进入吉他界面，程序选择目标游戏窗口。
2. 打开“布局与坐标校准”，自动切回所选游戏窗口并截图校准，核对圆盘扇区和扫弦点后应用。也可导入 PNG 或手动校准。
3. 按游戏实际填写当前模式、音色和起始页；混合模式分别填写和弦页与品格页。
4. 打开曲谱、导入 MIDI 或进入“图形编谱”。编谱右下角可直接载入原谱，也可选择近似转译，核对实际按法、省略音和时序提示。
5. 点“5 秒后自动演奏”，切回游戏。F8 暂停／继续，F9 停止；失去游戏焦点会停止并释放输入。

## 乐谱与演奏

- 点击六线谱弦线并输入 0～24 品，用音乐符号设置时值；支持多小节、附点、三连音和撤销／重做。
- BPM、拍号和清音／失真可在小节处变更，后续继承；支持 Capo 和从当前小节试听。
- 四页 24 个游戏和弦，支持分解拨弦、同拍多弦与上下扫弦。上扫为 **1→6 弦／鼠标左键**，下扫为 **6→1 弦／鼠标右键**。
- MIDI 可选择非鼓轨声部并保留速度变化；默认混合转译与自动升降调，也可选择单音旋律或纯品格指弹近似。
- 曲谱、MIDI 和 WAV 试听文件保存在程序旁的本地曲库。

和弦转译可选参考指法或本机实测音高表，本地合成试听是参考音色。按住时长按谱面发送，实际尾音随游戏音色而异；快速翻页和模式切换仍需准备间隔。暂停会打断延音，继续时重新触发当前选择项可恢复的音。跨小节延音目前按整列处理，独立声部重叠延音与 Guitar Pro 文件导入尚未完整支持。
