# Guitarplayer For NTE · 异环吉他编曲器

Windows 桌面吉他编谱与自动演奏工具。当前发布版本 **v0.8.0**。

## 下载

[下载 v0.8.0 完整发布包](./nte-guitar-player-v0.8.0.zip?raw=true)

压缩包包含程序源码、启动器、MIDI 解析依赖、示例曲谱、测试和完整文档。本仓库目前通过压缩包发布；源码在 ZIP 中的 `guitar_player/` 目录。

需要 **Windows、Python 3.10 或以上版本，以及 Tkinter**；这是源码发布包，尚未打成独立 EXE。完整解压后双击 `启动吉他编曲器.cmd` 或 `start.cmd`，不要在压缩包中直接启动。启动默认申请管理员权限，离线编谱可用 `start.cmd --no-admin`。

## 使用

1. 在游戏中打开吉他界面，程序选择目标游戏窗口。
2. 打开“布局与坐标校准”，点“3 秒后自动校准”，切回游戏。核对识别出的扇区和建议扫弦点，再应用。可改用 PNG 截图识别或手动拾取。
3. 核对当前模式、音色和游戏起始页，打开曲谱并先预演或试听。
4. 点“5 秒后自动演奏”，切回游戏。F8 暂停／继续，F9 停止；失去游戏焦点会停止并释放输入。

## 功能

- 点击六线谱弦线并键入品位，用音符图形选择时值；支持多小节、附点、三连音、撤销与重做。
- 小节 BPM、拍号与清音／失真标记，支持 Capo、从当前小节试听。
- 四页 24 个游戏和弦，支持分解拨弦、同拍多弦及上下扫弦。
- MIDI 单音声部导入，自动选择等音指法以减少翻页。
- 曲谱／MIDI／WAV 曲库保存在程序文件夹中。
- **v0.8.0 新增**圆盘自动校准、按模式记忆本机布局，以及历史日志调优。

日志调优从最近演奏日志估计本机输入和调度耗时，调整下次演奏的准备余量；不改变原曲 BPM、音符起音和时值，也不会自行改写程序。Windows 接收输入不能证明游戏已发声，真实漏音仍需实机核对。

## 示例与限制

包内有小星星、四页和弦测试、变拍／变速／音色／Capo 示例，以及童年约 19 秒扫弦版、约 35 秒和弦功能展示版等短伴奏演示。

Guitar Pro 导入、图片识谱、完整多声部和曲中混合和弦／品格模式尚未实现。和弦预演仅显示动作与节奏，游戏每弦音高未核对，暂不合成本地和弦试听。游戏窗口需处于前台。
