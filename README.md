# Guitarplayer For NTE · 异环吉他编曲器

Windows 桌面吉他编谱与自动演奏工具。当前发布版本 **v0.11.0**，提供独立 EXE，无需安装 Python。

## 下载

[下载 v0.11.0 Windows 便携包](https://github.com/DIEtype/Guitarplayer-For-NTE/releases/download/v0.11.0/NTE-Guitar-Player-v0.11.0-Windows.zip) · [全部版本](https://github.com/DIEtype/Guitarplayer-For-NTE/releases)

完整解压到可写的文件夹，双击 **NTEGuitarPlayer.exe**。正常演奏会申请管理员权限，以匹配游戏权限；离线编谱可带 `--no-admin` 启动。程序与窗口使用明音凛头像图标，图标来源和制作说明随包提供。

升级时保留原目录的 `library/`、`settings/` 和需要留存的 `logs/`；关闭旧窗口后再替换 EXE。发布包不包含个人曲库、校准配置或演奏日志。

## v0.11.0 更新

- **逐弦修改**：Del／Backspace 默认只删选中弦的音，保留同拍其他音、时值与后面的位置。`8` 改成 `7` 可直接键入 `7`，连续输入 `12` 仍表示十二品。
- **插入节拍**：Insert 打开独立的音乐时值选择窗口，支持附点和三连音；选择插入时值不会改动当前音。本小节空间不足时提示调整，下一小节保持原位。
- **明确的整列操作**：Shift+Del 清空整列音符并保留时值；Ctrl+Del 删除整列节拍并将本小节后续音符前移。支持 Ctrl+Z 撤销和 Ctrl+Y 重做。
- **统一编曲**：主界面与指弹转译采用同一个六线谱编辑器，可混写数字品位、和弦标记、逐弦 X／点和上下扫弦。
- **自动降调**：整曲比较原调至降低 24 个半音的方案，兼顾节奏可行性、丢音、切模式与翻页；保留旋律音程和原始起拍。可比较方案，并试听原谱与转译结果。
- **跨小节延音**：长音可延续到下一小节空位，谱面显示延音线，小节线处不重复拨弦。T 连接相邻同音，Shift+T 断开跨小节延音。
- **混合演奏**：在预设和弦与品格之间自动用 Z 切换；MIDI 指弹近似优先保留旋律起拍，尽量保留低音与内声部。

## 使用

1. 在游戏中进入吉他界面，程序选择目标游戏窗口。
2. 打开“布局与坐标校准”，自动切回所选游戏窗口并截图校准，核对圆盘扇区和扫弦点后应用。也可导入 PNG 或手动校准。
3. 按游戏实际填写当前模式、音色和起始页；混合模式分别填写和弦页与品格页。
4. 打开曲谱、导入 MIDI 或进入“图形编谱”。指弹原谱可送入“指弹转译”，查看实际按法、省略音和时序提示。
5. 点“5 秒后自动演奏”，切回游戏。F8 暂停／继续，F9 停止；失去游戏焦点会停止并释放输入。

## 乐谱与演奏

- 点击六线谱弦线并输入 0～24 品，用音乐符号设置时值；支持多小节、附点、三连音和撤销／重做。
- BPM、拍号和清音／失真可在小节处变更，后续继承；支持 Capo 和从当前小节试听。
- 四页 24 个游戏和弦，支持分解拨弦、同拍多弦与上下扫弦。上扫为 **1→6 弦／鼠标左键**，下扫为 **6→1 弦／鼠标右键**。
- MIDI 可选择非鼓轨声部与整轨移调，保留速度变化；可选择单音旋律或指弹近似。
- 曲谱、MIDI 和 WAV 试听文件保存在程序旁的本地曲库。

和弦转译可选参考指法或本机实测音高表，本地合成试听是参考音色。游戏中的实际延音由采样决定；快速翻页和模式切换仍需准备间隔。跨小节延音目前按整列处理，独立声部重叠延音与 Guitar Pro 文件导入尚未完整支持。
